# Solid Antipatterns

Apply SOLID only where responsibilities and contracts warrant it, never mechanically to simple functional React components.

Inspect God Objects, spaghetti code, unexplained magic numbers, copy-paste with divergent maintenance, feature envy, and hidden dependencies. Repetition, local literals, or file length alone do not prove a problem. Account for intentional duplication and FSD boundaries.

For each issue give location, severity, why it matters specifically here, concrete maintenance/defect impact, and minimum reasonable refactor. Avoid new abstractions merely to satisfy a principle.
