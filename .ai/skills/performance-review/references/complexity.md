# Complexity

Analyze relevant functions using named input dimensions. Report current time complexity, auxiliary space complexity, exact line/operation causing cost, realistic scale/frequency where it matters, possible optimization, and complexity afterwards. State average/worst-case and data-structure assumptions.

Do not optimize ordinary O(n) over small bounded data without a reason. Nested loops alone do not prove a bottleneck. Include caller repetition, built-in operation costs, and memory/readability tradeoffs.
