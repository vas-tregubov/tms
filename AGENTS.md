# TMS Agent Instructions

Before making changes, read the relevant project documentation.

Always read:

- README.md
- CONTRIBUTING.md
- docs/code-style/README.md
- docs/domain-model.md

For frontend tasks, also read:

- docs/code-style/frontend.md

For backend tasks, also read:

- docs/code-style/backend.md

For UI / Figma tasks, also read:

- docs/design-system/README.md
- .agents/skills/figma-to-react/SKILL.md

General rules:

- Follow the existing project architecture and conventions.
- Inspect the existing implementation before changing it.
- Prefer the simplest solution that satisfies the current requirement.
- Reuse existing components, utilities, styles and design tokens before creating new ones.
- Do not add speculative functionality, abstractions or dependencies.
- Do not modify unrelated parts of the project.
- Before changing files, briefly show the implementation plan and wait for user approval.
- After implementation, run the relevant project checks and summarize the changes.
- Keep project documentation in English.
